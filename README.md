## Project Overview

This project focuses on customer intelligence, customer retention, and business growth analytics using Python and Tableau. The analysis is performed on e-commerce customer behavior data to generate meaningful business insights and interactive dashboards.

The project demonstrates:

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Customer behavior analysis
* Revenue and sales trend analysis
* Customer retention insights
* Interactive Tableau dashboards
